# v1.0.59 — Conversational & Photo-Assisted Commissioning Foundation

The simple Home Assistant path lets a user select an area, describe plants and visible
delivery in ordinary terms, review IrrigationOS's deterministic interpretation, and confirm
before saving. Existing advanced editing and calibration remain available.

The fusion layer combines user-confirmed facts and approved structured visual findings while
preserving provenance, confidence, conflicts, assessment references, sharing, throw, and
spray pattern. It stores no raw photos and calls no external vision provider.

Generic delivery references are injected provider-neutral catalog evidence. They may carry a
range only when documented. Color alone never fabricates flow, pressure, application rate, or
hydraulic sufficiency. Wide ranges can suggest optional measurement; conflicts request human
confirmation.

Schema 6 adds optional approximate-flow-range evidence. Schemas 1–5 migrate additively with
that evidence absent. No recommendation, runtime, schedule, command, execution authorization,
or Live-control authority is created.
