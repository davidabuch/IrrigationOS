# v1.0.36 — First Supervised Live Trial Acceptance

This milestone separates supervised first-live commissioning from autonomous promotion maturity.

A supervised trial may be eligible before the 10-day / reconciliation promotion criteria mature, but only when controller ownership and execution-boundary review are acknowledged, system health and observations are current, controllers and pipeline are available, no watering conflict exists, all six live-mode safeguards remain implemented, all integrated validation scenarios pass, the supervised window is open, and a valid single-use operator approval is present. The 120-second ceiling, durable audit-before-dispatch, and no-automatic-retry behavior remain unchanged. Autonomous Live control remains disabled.
